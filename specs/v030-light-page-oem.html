Light page in the OEM skin

The real 480 × 320 Light page in the 90s Mitsubishi OEM style. Updated 2026-10-19 to the S105 build rulings (Iris L1–L7, Atlas A3/A7/L1–L6). The simulated sensor sweeps from night to full sun and back; watch the gain word change in daylight and the dot ride the auto-dim curve. The word, the level, the reason codes and the curve points all come from the sensor bridge. The page holds one applier and one log function, and computes no level and no band.

What the page reads

  • The bridge decides, the page draws. lightBand, brightnessLevel, brightnessMode, reasons.lux, atLimit and curve.points all come from states/light. Switch the config above: the boundary and the line move and no page code changes.
  • A lux is a reading only if it is finite and ≥ 0. Otherwise the provider publishes lux null with reasons.lux at_limit or no_reading; the page maps the code through one table.
  • VISIBLE is the published visibleCount. The page never subtracts; a null reads --, never a floored 0.
  • RANGE is the gain word as published (low, med, high, max) and 100 ms. No multiplier: that would need a page gain table.

The applier and the status

  • One applier: appliedBrightness() returns {level, basis}: alarm ⇒ 1.0 alert; fresh ⇒ the published level and mode; otherwise the injected defaultLevel, fallback. The panel, the status line and the dot all read it.
  • Status from basis, never from brightnessMode: BRIGHTNESS AUTO nn %; default or fallback BRIGHTNESS nn % (default, no reading) (405.6 px of 456); alert BRIGHTNESS 100 % (alert). A stale file that says auto can never show AUTO.
  • Not drawn: the override line and the SETTINGS shortcut. Both wait for the F-126 brightness row.

Reading the curve

  • X axis is log lux over the published points (0.3 to 30,000). luxAxisX() is the only function that takes a log, and only to place a lux on the axis.
  • Y axis runs from minLevel − 0.25 to 100 % (0.5–1.0 today). Labels 100%, 75%, 3 and 300 lux, all at --fs-meta.
  • The dot sits at the APPLIED level. Fresh auto: on the line. Stale fallback: the default level, off the line, dimmed. Alert: 100 %.
  • ⚠️ Flat to the knee. The line stays flat at 75 % up to about 94.9 lux and climbs to 100 % at 300 lux. NIGHT and DUSK both dim to 75 % on this car. Whether that is wanted is a tuning question for the in-car check.
  • A channel at the limit reads at limit in amber on its own cell and on VISIBLE, which is derived from it.
