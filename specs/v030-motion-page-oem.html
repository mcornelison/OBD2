Motion page in the OEM skin

The real 480 × 320 Motion page in the 90s Mitsubishi OEM style, layout A: pitch and the 15-minute grade trend on top, g-force as numbers in the middle, sensor health at the bottom. The simulation publishes once a second, as the motion sensor does. Use the switches to brake, corner, break the gyro, stop the sensor publishing or start a new drive. Updated 2026-10-19 to the S105 build rulings (M1–M7, Atlas B5/C1–C3): every panel text in the mono face, TILT FIX split by size, a null grade point breaks the line, zero pitch reads level, a GYRO that was never judged reads --, ages floor and cap at 999+ s ago.

What the page reads

  • Pitch is states/imu.pitchDeg. When reasons.pitchDeg is gyro_implausible it shows -- with the reason, and GYRO turns amber.
  • ACCEL / BRAKE follows the sign of gLon (+ = accelerating). CORNER L / R follows gLat (+ = right).
  • Peaks are peaks.accelG / brakeG / leftG / rightG, published by the sensor bridge with sinceTs. The provider resets them to null at drive start (US-892-a); a null peak reads --.
  • Stale is pi.display.stale.imuSec, default 3.0 s, strict age > imuSec. It is the same key the Navigation page uses.
  • Grade is states/grade-history: 90 points, one per 10 s over 15 min. Line, end dot and end label share one scale, and the label is the last point.

Rules drawn here

  • The grade line is orange because grade has no band. Nothing on this page uses a state colour except the two health warnings.
  • TILT FIX with no stops reads -- and no stops yet, never 0.00°.
  • COMPASS reads -- + not published with the legacy fusion engine, which publishes no calibration flag. That is not the same as "not calibrated". The text is the one shared CALIBRATION_ABSENT_TEXT; NAV prefixes it with calibration (US-911).
  • No g meter, dot or trail (US-733). Values step once a second with no animation between readings.
  • Health is a 2 × 2 grid, columns 1fr max-content. Measured in the shipped mono face, the right column takes not calibrated (168.6 px), so the left gets 271.4 px. TILT FIX is split by size: the value at --fs-label, from N stops at --fs-meta; the worst case −10.00° + from 999 stops is 216.7 px.
  • A reason never sizes a column: contain: inline-size on the reason, so it wraps inside its own column.
  • Ages floor and read N s ago, capped at 999+ s ago. The age shows only in UPDATED; the health block never dims.
  • The grade label has no middle dot: the Michroma subset has none, so it would fall back to another font mid-label.
