Warnings page in the OEM skin

The real 480 × 320 Warnings page in the 90s Mitsubishi OEM style, brought up to the merged spec on 2026-10-22. Every active entry is in one list, ranked by the provider, and the list scrolls when it runs long. The warning icon in the top bar shows on every page. Two screens can cover the page. PULL OVER is for a live coolant red only, and it can't be dismissed. The code alert shows stored codes once per key-on; it can be dismissed, and it is never drawn while the car moves. Parked, a tap on a code row opens its detail, where the Clear button says what unlocks it. Pick a scenario, then switch the page underneath, drive off, go stale, acknowledge, or let a write fail.

What the page reads

  • Only states/alerts, except in the code detail. Each entries[] row is {id, source, key, tier, title, sentence, value, unit, round, firstSeenTs, active, stale, acknowledged}, already in the provider's order: tier, then live before stored, then newest. The page never sorts.
  • The icon renders icon.state, icon.count and icon.pulse as given: △ tertiary, amber ?, amber ▲n, red ▲n, and -- tertiary with no payload (never △: that would claim the codes were read). MINOR- or UNRATED-only is watch (Atlas G7): counted means amber. Above 99 it reads ▲99, in a fixed 3-character slot.
  • Words are the provider's: titles, sentences and the takeover's directive. Codes read EGR FLOW (P0400); an unrated code is the bare code with Severity unknown. Get it diagnosed. No P0430: bank-2 codes can't set on this inline four.
  • Values go through displayUnits(value, unit, round). Conversion first (coolant °C ⇒ °F), and the provider's round direction last: battery low 11.96 floors to 11.9 V, high 15.04 ceils to 15.1 V. No threshold reaches the page.
  • Ages: rows use agoText (just now, n min ago, 41 days ago), with no source prefix. A stale reading says last reading n s ago, capped at 999+ s ago.
  • Only what was assessed. In the checked, nothing-found state, each unassessed source gets its own line in --text-secondary: System checks not read yet. until the first verdict, and Data checks are not built yet. The NOT CHECKED state adds neither.

Rules drawn here

  • Red is the STOP tier only, and today that means a live coolant red. A red RPM or battery tile is a WATCH entry with an amber icon. The tile shows where the value is; the tier says what to do.
  • PULL OVER reuses the shipped STOP skeleton: an opaque field, an 8 px red frame on stop-alarm-pulse (inside prefers-reduced-motion: no-preference), white copy, full brightness, no button. A tap stops the icon pulse only. Stale, it stays up with the last value, and last reading n s ago goes on its own --fs-label line.
  • The code alert uses the same skeleton with no pulse and no brightness override. Its frame is TIER_COLOR_VAR[codeAlert.tier], the provider's tier. It has one real button, DISMISS, and is not drawn while not parked (hiding it isn't a dismiss). PULL OVER outranks it.
  • The clear lock says what unlocks it. Parked is gear P or N held 8 s (CIO 2026-10-22). stop to clear shows only when not being parked is the sole blocker, and gear unknown takes its place while states/gear is unavailable (the shipped clearButtonView: moving replaces only ok; parked_unknown is new). Every other reason wins, because stopping would not unlock it: a WATCH or unrated code, a sync still pending, pending codes not read, a code that came back (Atlas, US-919, 2026-10-21). Which non-ok reason shows first is the gate's order, not the page's.
  • Detail fetch fails: the entry's own chip, title and sentence, plus details unavailable. No Clear control is drawn: the fetch is what feeds the gate. ⚠️ The spec doesn't name this case yet; flagged.
  • REPLAY stays on top. The data-source marker sits above both screens.
  • Fit (measured): PULL OVER 345.7 px at 44 · ENGINE OVERHEATING 416.1 px at 26 · TROUBLE CODES 315.5 px at 26 · DISMISS 123.0 px at 20 · NOT CHECKED 352.7 px at 34 (Michroma). The widest chip, UNRATED, is 107 px, so the chip column is 116 px, and the worst row (999 days ago) is ~457 of 456 px. The title wraps there; it never clips.
  • Top bar: the S108 four-item cluster at 26 px (chain 3ch · ⇅ · WiFi SVG · the icon), 159.4 of 168.6 px. Other OEM mockups draw a word stand-in; the spec's widths govern the build.
