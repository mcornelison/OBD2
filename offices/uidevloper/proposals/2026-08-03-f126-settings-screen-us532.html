Real values, honest saves

Every control reads the effective value from the state server (US-530), not a hardcoded default. A subtle set vs default marker shows whether it's an operator override or the shipped default.

On tap: saving… → confirmed from a re-read (saved), or on a rejected/failed write it snaps back to the real value + couldn't save — never an optimistic "on". The write is token-gated (US-531).

Apply-state per row

Auto-rotate / Power / Audio → live; Auto-analyze → next drive; Calibration → restart needed. A setting that isn't instant says so — no silent no-op that looks applied. (Exact per-setting timing comes from the US-533 wiring; the card shows what it reports.)

Power mode = 3-state

CAR / WALL / UNKNOWN (not a toggle). Setting WALL fixes the bench "unknown" — the System-Status power tile then reads WALL.

Reconciled with the setup menu

Settings (safe prefs) = this card. Destructive service control + Exit stay in the US-403 long-press menu — reachable via the Service & Exit › row; the menu gets a ⚙ Settings row back. No competing surfaces.
