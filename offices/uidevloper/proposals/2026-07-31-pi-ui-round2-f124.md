## C · Carousel navigation (#12 wrap + #13 auto-rotate)

**C-1 Wrap (#12):** the carousel **wraps** both directions (last → first, first → last). **Hidden / vehicle-gated
cards are SKIPPED** — wrap (and auto-rotate) traverse only *visible* cards, so a bench-hidden LTFT card is never
landed on. (Replaces the current "no silent wrap" clamp — CIO override.)

**C-2 Auto-rotate + swipe-to-pause (#13, net-new).** The model:
- **Auto-cycle** every **`autoRotateS` = 8 s** (proposed) through the visible cards, wrapping. A thin top progress
  bar shows time-to-next (calm, not a countdown number).
- **Slow / settle swipe** (deliberate) → moves one card **and PAUSES** auto-rotate (you're reading it).
- **Fast / hard swipe** (flick) → advances one card **and RESUMES** auto-rotate.
- **Tap on a card** (or opening any overlay) → pauses (you're interacting).
- **Auto-resume** after **`resumeIdleS` = 45 s** (proposed) of no interaction, so it never stays frozen forever.
- **Slow-vs-fast = a velocity model** (today swipe is distance-only). At pointer-up compute `v = dx / dt` (px/ms);
  **fast if `|v| ≥ 0.6 px/ms`** (proposed) OR travel ≥ ~55% of screen width; else slow. Distance threshold to count
  as a swipe at all stays ~40 px. All three constants land in config (`pi.display.carousel.*`).

## D · System-Status "1 ISSUE" drill-down (#7)

Today `SYSTEM · 1 ISSUE` is presentation-only (P-1 was deliberately no-drilldown). Make the **summary line tappable →
a drill-down overlay**:
- Lists the degraded source(s) **worst-first**: each row = source label · state chip (amber/red) · the honest reason ·
  freshness (`seen Ns ago`). One row per non-OK source; if only one, it's a single focused block.
- A **‹ Back** returns to the card (never traps). Opening it pauses auto-rotate (interaction).
- Honest-instrument: it only ever lists what's *actually* degraded (green sources never appear); mirrors the DTC
  detail pattern so the interaction language is consistent.

## E · Steady "parked" signal for the kebab (#15)

Kebab `⋮` visibility currently keys off raw `system-status.idle`, which flips with **OBD availability** — an OBD blip
toggles the kebab. Define a **debounced `parked` signal**:
- **`parked` = `idle` held true for ≥ `parkedOnS` (8 s), reverting only after `idle` false for ≥ `parkedOffS` (3 s)**
  (hysteresis). Brief blips don't flip it. Kebab visibility (Option C, context-aware) keys off `parked`, not `idle`.
- **Near-term:** the display debounces the `idle` it already consumes — **no new contract**.
- **SSOT end-state:** the emitter writes a debounced `parked` boolean (cleaner one-fact-one-owner). **This is the same
  class as my open idle-SSOT question to Atlas** — I'll fold it in: *if* `parked` becomes an emitter field, Atlas owns
  it. **Flag: needs an Atlas nod only if we go emitter-side.** Recommend display-debounce now.

*(#11 FYI — LTFT visible on bench: a gate bug in dev's lane. My C-1 "skip hidden cards in wrap/auto-rotate" assumes the
gate works; if a card is wrongly visible that's the gate bug, not the nav model.)*
