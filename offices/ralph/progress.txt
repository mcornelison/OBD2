### Learnings for future iterations:
- **Pattern discovered**: The capture race was invisible to lifecycle-mocked tests because the logger read self.connection.obd.query() DIRECTLY -- any connection double must now expose query() (delegating to .obd.query) to model the wrapper faithfully. Route the logger through the wrapper, not the raw obd, so the test path == production path (avoids Atlas's "mocked-green/IRL-miss" trap).
- **Gotcha**: MagicMock connections auto-return a MagicMock from any attribute, so activeGeneration() must be isinstance(int)-gated (MagicMock is not int) and .query() must be explicitly wired to the scripted BT edge in e2e fixtures (a bare .query returns a junk response, never hitting is_null()).
