### Learnings for future iterations:
- **Pattern (adopt-uncommitted, 2nd time this sprint)**: uncommitted work at session start matching the claimed story is the recurring headless stall. DON'T blind-commit -- inspect end-to-end, prove each AC yourself, run the gate SYNCHRONOUSLY, and check the LEFTOVERS the stall skipped (here: the AC#6 doc was never written and one new test file was never ruff'd). The commit is the last step, not the first.
- **Gotcha (in-sprint Rule-10 doc is a per-story AC, not just US-425's job)**: AC#6 required the architecture.md data-contract update IN this story. A dedicated doc-sync story (US-425) later in the same sprint does NOT discharge another story's own Rule-10 DoD AC -- if an AC names architecture.md, land it in-story or the story isn't strictly passing.
- **Gotcha (derived-CHECK still needs the literals pinned)**: the SSOT derives DATA_SOURCE_CHECK_CLAUSE, but the 9 per-table schema strings are hand-written literals -- they only stay in lockstep because test_everySchemaCheckMatchesSsot re-parses each and asserts equality to the tuple. When adding an enum value, widen every literal AND trust the parity test to catch a miss, rather than assuming 'derived' means 'auto-updated everywhere'.
- **Gotcha (resize-droppable is a sanctioned compression, not scope-cut drift)**: US-424's pmSignOff pre-authorized dropping the server tripwire if the L ran heavy. Dropping it kept the story to one clean iteration -- but only because the drop was explicitly blessed. Never silently drop an AC; a pre-blessed relief valve is the exception.
