### Learnings for future iterations:
- **Pattern discovered**: when two acceptance clauses genuinely conflict, pick by WHICH
  READING LETS THE NEXT STORY BE BUILT AS WRITTEN. Here "5 tokens" vs "pixel identical"
  was unresolvable on its own terms (15 shipped sizes, 5 slots); the tiebreak was that a
  lossless design would have left US-540-a setting 5 of 15 values. File the deviation,
  do not block the sprint's prereq story on it.
- **Pattern discovered**: a refactor that changes how a value is SPELLED must first find
  every test that PARSES the old spelling. `grep -rn 'font-size' tests/` took ten seconds
  and found two safety guards that would have silently gone blind rather than red.
- **Gotcha**: `ruleBlock()` must be line-anchored. A substring search for
  `.takeover-directive {` finds the STOP OVERRIDE first (declared earlier in the sheet),
  so a guard comparing an override to its base compares it to itself and passes at 40>40.
- **Gotcha**: a COMMENT containing the literal `@import` fails two offline-kiosk font
  guards that scan raw file text. Reword the comment; never weaken the guard.
- **Gotcha**: the Bash tool is bash -- PowerShell here-strings (`@'...'@`) leak a literal
  `@` into the commit subject. Use a real heredoc or `git commit -F <file>`. `/tmp` and
  `.git/` are both blocked for writes; stage scratch files inside the repo.
